## About This Project
This repository contains three cybersecurity projects completed as part of my CodeElevate Cybersecurity Analyst Internship.

## Task 1: Security Log Analyzer
- Language: Python
- Analyzes sample security logs.
- Counts failed login attempts by IP address.
- Flags IP addresses that reach the configured threshold.

## Task 2: Password Strength Checker
- Language: Python
- Checks password length and character types.
- Classifies passwords based on the implemented rules.

## Task 3: Website Security Assessment
- Tool: Google Chrome Developer Tools
- Reviews HTTPS, certificate information, and observable response headers.
- Documents findings and recommendations from passive browser inspection.

## Tools Used
- Python
- Visual Studio Code
- Google Chrome Developer Tools
- Markdown

## Disclaimer
These projects are intended for educational purposes. The website review was limited to passive browser inspection and was not a penetration test.
